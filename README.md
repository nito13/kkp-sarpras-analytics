# SARPRAS KKP — Sistem Informasi & Analitik Sarana Prasarana Satuan Pendidikan Kelautan dan Perikanan

Aplikasi web analitik data modern dan interaktif berstandar kedinasan untuk memonitor, menginventarisasi, menganalisis kelayakan, dan mensimulasikan prioritas alokasi anggaran **Sarana dan Prasarana (Sarpras)** pada seluruh **Satuan Pendidikan di lingkungan Kementerian Kelautan dan Perikanan (KKP)** — di bawah naungan **Badan Penyuluhan dan Pengembangan Sumber Daya Manusia Kelautan dan Perikanan (BPPSDM KP)** dan **Pusat Pendidikan Kelautan dan Perikanan (Pusdik KP)**.

## 🚀 Fitur Unggulan Sistem

### 1. 📊 Executive KPI Dashboard
- **Metrik Kunci Real-Time**: Total Unit Sarpras, Valuasi Total Aset BMN (Rupiah), Indeks Kelayakan Sarpras Nasional (IKSP %), Unit Kondisi Baik, Unit Rusak Kritis, dan Kebutuhan Anggaran Rehabilitasi.
- **Visualisasi Grafik Chart.js**:
  - *Donut Chart*: Komposisi kondisi fisik aset (Baik, Rusak Ringan, Rusak Berat).
  - *Horizontal Bar Chart*: Peringkat kelayakan sarpras antar-kampus (Politeknik vs SUPM).
  - *Radar & Progress Matriks*: Kepatuhan dan kesiapan fasilitas per 8 Bidang Sarpras terhadap standar minimum KKP.
- **Critical Alert Ticker**: Informasi berjalan untuk peringatan dini sarpras prioritas (misal mesin kapal rusak atau masa berlaku sertifikat BKI habis).

### 2. 🗺️ Peta Geospasial Interaktif Nusantara (Leaflet Engine)
- **Multi-Tile Layer Asli**: Pilihan peta interaktif dunia nyata:
  - *Peta Jalan (OpenStreetMap)*
  - *Citra Satelit Resolusi Tinggi (Esri World Imagery)*
  - *Peta Topografi Medan (OpenTopoMap)*
  - *Peta Terang Kontras (CartoDB Positron)*
- **Interactive Campus Pins**: Dilengkapi efek denyut (*pulsating glow*) berkode warna (*Emerald* $\ge 85\%$, *Sky* $75-84\%$, *Rose* $<75\%$).
- **Drawer & Filter Terintegrasi**: Filter peta berdasarkan Satdik dan Program Studi, dilengkapi panel detail samping (*slide-over drawer*) yang responsif di desktop maupun perangkat mobile.

### 3. 📦 Inventaris & Katalog Sarpras Pintar
- **Filter Multidimensi**: Pencarian nama sarpras/spesifikasi, filter Satdik, filter Bidang Sarpras, filter Program Studi, filter Kondisi Fisik, dan filter Urgensi Pemeliharaan.
- **Dual View Mode**:
  - *Tampilan Tabel Data*: Terstruktur, dapat diurutkan (*sortable* kolom), dilengkapi badge Program Studi, bar kemajuan utilisasi, dan skor kelayakan.
  - *Tampilan Grid Kartu*: Kartu visual informatif dengan ikon spesifik sesuai kategori sarpras.
- **Modal Detail Teknis & Editor Cepat (Quick & Full Edit)**:
  - Inspeksi detail mesin, kapasitas operasional, legalitas sertifikasi, catatan teknis, dan jadwal pemeliharaan.
  - Penyuntingan data langsung tersinkronisasi ke *Local Storage* dan backend API.

### 4. 🎓 Analisis Standar Vokasi & Komparasi Kampus
- **Daya Tampung Asrama Taruna**: Analisis ketersediaan ranjang/tempat tidur dan persentase kelayakan gedung asrama penunjang di 18 satuan pendidikan.
- **Sertifikasi Armada Kapal Latih**: Status kelaiklautan berstandar IMO STCW dan Biro Klasifikasi Indonesia (BKI).
- **Katalog 25 Program Studi**: Informasi kampus pengampu dan badge Bidang Sarpras yang menaunginya.
- **Head-to-Head Campus Comparison**: Komparasi langsung antar dua kampus terpilih untuk membandingkan kapasitas fasilitas, luas lahan/bangunan, valuasi BMN, dan rasio kelayakan.

### 5. ⚠️ Early Warning System & Pemeliharaan Kritis
- Identifikasi otomatis aset berstatus **Rusak Berat** atau berurgensi **Kritis / Segera**.
- Analisis dampak operasional terhadap proses belajar-mengajar taruna vokasi.
- **Jadwal Docking & Kalibrasi 2026/2027**: Kalender pemeliharaan berkala untuk kapal latih, kompresor dive center, boiler pabrik pakan, dan lab pengujian.

### 6. 💡 Simulator Alokasi Anggaran APBN / RKA Prioritas
- **Interactive Budget Slider**: Pengaturan pagu anggaran dari Rp 1 Miliar hingga Rp 50 Miliar.
- **Real-Time Projection**: Menghitung proyeksi peningkatan Indeks Kelayakan Nasional, unit rusak berat yang terdanai, dan sisa alokasi pagu.
- **Tombol "Terapkan Hasil Simulasi Ini"**: Langsung memperbarui status kelayakan sarpras secara live di sistem.
- **Ekspor Format RKA**: Unduh usulan prioritas anggaran langsung ke format Excel resmi.

### 7. 📑 Ekspor Dokumen Resmi Microsoft Excel (.xlsx Asli)
- Dibangun dengan pustaka `xlsx-js-style` yang menghasilkan file `.xlsx` asli (bukan `.csv` tiruan).
- **Kop Surat Kedinasan Resmi**: Kop Kementerian Kelautan dan Perikanan & BPPSDM KP.
- **12 Kolom Terstruktur Rapi**:
  `No.` | `ID Sistem` | `Nama Sarana & Prasarana` | `Satuan Pendidikan` | `Program Studi` | `Bidang Sarpras` | `Kondisi Fisik` | `Skor Kelayakan` | `Tingkat Utilisasi` | `Tahun Perolehan` | `Urgensi Pemeliharaan` | `Catatan Teknis`
- **Lembar Pengesahan Tanda Tangan Ganda**: Blok tanda tangan resmi Koordinator Sarpras Pusdik KP dan Petugas Operator Sistem beserta stempel waktu cetak.

## 🛠️ Arsitektur Teknologi

- **Frontend Core**: [React 19](https://react.dev/) + [Vite 8](https://vitejs.dev/)
- **Styling & Desain**: [Tailwind CSS v4](https://tailwindcss.com/) dengan palet maritim *Deep Ocean Navy, Slate & Electric Cyan*
- **Peta Geospasial**: [Leaflet](https://leafletjs.com/) + [React-Leaflet](https://react-leaflet.js.org/) dengan tile layer OpenStreetMap, Esri Satellite, OpenTopoMap, CartoDB Positron
- **Visualisasi Grafik**: [Chart.js](https://www.chartjs.org/) + [react-chartjs-2](https://react-chartjs-2.js.org/)
- **Ekspor Dokumen**: [xlsx-js-style](https://github.com/gitbrent/xlsx-js-style) untuk pembuatan spreadsheet Excel resmi ber-styling lengkap
- **Ikon Antarmuka**: [Lucide React](https://lucide.dev/)
- **Backend API (Opsional / Full-Stack)**: PHP 8.x Native RESTful Endpoint (`backend/api/`)
- **Database Engine (Opsional / Full-Stack)**: MySQL 8.x Laragon (`backend/database/schema.sql`)
- **State Management & Sinkronisasi**: React Context + Browser `localStorage` + REST API Sync

## 💻 Panduan Instalasi & Menjalankan Aplikasi

Aplikasi berada di direktori Laragon:
📍 **`C:\laragon\www\kkp-sarpras-analytics\kkp-sarpras-analytics`**

### Pilihan 1: Mode Pengembang Frontend (Hot-Reload)
Pastikan Node.js telah terpasang di komputer Anda:
```bash
# Masuk ke direktori proyek
cd C:\laragon\www\kkp-sarpras-analytics\kkp-sarpras-analytics

# Pasang dependensi proyek jika baru pertama kali (opsional)
npm install

# Jalankan server pengembangan Vite
npm run dev
```
Buka peramban di: **[http://localhost:5173/](http://localhost:5173/)**

### Pilihan 2: Build Rilis Produksi
Untuk mengompilasi bundel rilis siap pakai ke folder `dist/`:
```bash
npm run build
```

### Pilihan 3: Konfigurasi Database MySQL Laragon (Backend PHP)
1. Buka aplikasi **Laragon**, klik tombol **Start All** (Apache & MySQL aktif).
2. Buka HeidiSQL atau phpMyAdmin (klik menu **Database** di Laragon).
3. Buat database baru bernama: `kkp_sarpras_db`.
4. Eksekusi berkas SQL yang telah disediakan:
   - **`backend/database/schema.sql`** (Membuat tabel satdik, users, dan assets).
   - **`backend/database/seed_data.json`** dapat diimpor melalui endpoint migrasi PHP di `backend/api/migrate.php`.
